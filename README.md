# 🫧 보글보글 온라인

친구와 함께 브라우저에서 즐기는 보글보글(Bubble Bobble) 스타일 협동 게임입니다.
방 코드를 공유하면 최대 4명까지 같은 화면에서 함께 플레이할 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

실행하면 콘솔에 주소가 표시됩니다.

- 내 컴퓨터: `http://localhost:3210`
- 같은 와이파이의 다른 기기: `http://192.168.x.x:3210` (콘솔에 표시된 주소)

포트를 바꾸려면 `PORT=8080 npm start` (PowerShell에서는 `$env:PORT=8080; npm start`).

## 친구와 같이 하는 방법

1. 한 명이 서버를 실행하고 브라우저에서 접속합니다.
2. 닉네임을 넣고 **새 방 만들기** 를 누릅니다.
3. 화면 위쪽의 **방 코드**(예: `A3KP`)를 친구에게 알려줍니다. 코드 부분을 클릭하면 초대 링크가 복사됩니다.
4. 친구는 같은 주소에 접속해서 코드를 넣고 **방 참가하기** 를 누릅니다.

### 친구가 다른 집에 있다면

서버를 인터넷에 노출해야 합니다. 가장 간단한 방법들:

| 방법 | 명령 | 비고 |
| --- | --- | --- |
| Cloudflare Tunnel | `cloudflared tunnel --url http://localhost:3210` | 설치만 하면 바로 공개 주소가 나옴 |
| ngrok | `ngrok http 3210` | 무료 계정 필요 |
| Tailscale | 양쪽에 설치 후 서버 PC의 Tailscale IP로 접속 | 지인끼리 쓰기 편함 |

공유기 포트포워딩(3210/TCP)도 가능하지만 위 방법이 더 간단하고 안전합니다.
같은 와이파이인데 접속이 안 되면 Windows 방화벽에서 Node.js의 사설 네트워크 접근을 허용해 주세요.

## Render 배포

저장소에 [`render.yaml`](render.yaml)이 있으므로 Render의 **Blueprint** 로 만들면 설정이 자동으로 잡힙니다.
직접 만들 때는 반드시 아래를 지켜야 합니다.

| 항목 | 값 |
| --- | --- |
| 서비스 종류 | **Web Service** (Static Site 아님) |
| Root Directory | **비워 둘 것** (`public` 으로 지정하면 안 됨) |
| Build Command | `npm ci` |
| Start Command | `npm start` |

WebSocket 서버가 필요하므로 Static Site 로 만들면 동작하지 않습니다.

### Not Found 가 뜰 때 확인 순서

1. `https<주소>/healthz` 에 접속합니다.
   - **JSON이 나오면** Node 서버는 정상입니다. `publicFiles` 에 `index.html`이 있는지 확인하세요.
   - **Render의 "Not Found" 페이지가 나오면** 요청이 앱까지 오지 않은 것입니다 → Static Site 로 만들었거나 서비스가 죽어 있습니다.
2. 파일 경로를 잘못 요청하면 앱이 `[bubble-bobble-online] 파일을 찾을 수 없습니다` 라고 답합니다.
   이 문구가 보이면 라우팅은 정상이고 파일만 없는 것입니다.
3. Render 대시보드의 **Logs** 에서 `보글보글 온라인 서버 실행 중` 문구가 찍혔는지 확인합니다.

무료 플랜은 15분간 접속이 없으면 서비스가 잠들었다가 다음 접속 때 30초쯤 걸려 깨어납니다.

## 조작

| 동작 | 키 |
| --- | --- |
| 이동 | `←` `→` 또는 `A` `D` |
| 점프 | `Space` / `↑` / `W` (한 번 누르면 항상 같은 높이로 1회) |
| 버블 발사 | `Z` / `X` / `Shift` / `Enter` |

모바일에서는 화면 아래 터치 버튼이 나옵니다.

## 게임 규칙

- 적에게 버블을 쏴서 가둔 뒤, 버블에 몸으로 부딪히면 처치됩니다.
- 연속으로 터뜨리면 **콤보**로 점수가 2배씩 올라갑니다 (100 → 200 → 400 → …, 최대 6단계).
- 처치하면 과일이 떨어집니다. 잠깐 뒤에 주우면 추가 점수(100~1000점).
- 가둬 놓고 오래 두면 적이 **화난 상태**(빨간색)로 탈출해 훨씬 빨라집니다.
- 빈 버블 위에는 **올라탈 수 있습니다.** 버블은 떠오르므로 높은 발판으로 갈 때 쓰세요.
- 적에게 닿으면 잔기가 줄고 잠시 무적 상태로 부활합니다. 전원이 잔기를 다 쓰면 게임 오버 후 자동으로 처음부터 다시 시작합니다.
- 스테이지 4개를 순환하며, 한 바퀴 돌 때마다 적이 빨라집니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `server.js` | HTTP 정적 서빙 + WebSocket 게임 서버. 게임 상태를 60Hz로 진행하고 30Hz로 스냅샷 전송 |
| `public/shared.js` | 맵 데이터와 물리 코드. **서버와 클라이언트가 같은 파일을 씁니다** |
| `public/game.js` | 접속, 입력, 로컬 예측, Canvas 렌더링 |
| `public/index.html` | 로비 화면과 HUD |

서버가 모든 판정의 권위를 갖고, 클라이언트는 자기 캐릭터만 같은 물리 코드로 미리 계산해서
지연 없이 반응하도록 했습니다. 서버 위치와 5px 이상 어긋나면 부드럽게, 24px 이상 벌어지면 즉시 보정합니다.
